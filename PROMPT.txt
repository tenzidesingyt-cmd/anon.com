ПРОМПТ ДЛЯ СОЗДАНИЯ ПОЛНОЦЕННОЙ СОЦИАЛЬНОЙ СЕТИ

Создай полноценный веб-сайт социальной сети, который по UX напоминает лучшие идеи X/Twitter и ВКонтакте, но не копирует их напрямую. Проект нужно делать поэтапно, с чистой архитектурой, понятными файлами и хорошим дизайном.

Стек для большой версии:
- Frontend: React + Vite + TypeScript + Tailwind CSS.
- State/API: TanStack Query.
- Backend: Node.js + Express + TypeScript.
- Database: PostgreSQL + Prisma.
- Sessions/cache: Redis.
- Realtime: Socket.IO.
- Auth: JWT access token + refresh token.
- Uploads: локальная папка uploads с возможностью перейти на S3/MinIO.
- DevOps: docker-compose для client, server, PostgreSQL и Redis.

Функции:
1. Регистрация и вход по email, username, password.
2. Хеширование паролей bcrypt.
3. Профили пользователей: аватар, имя, username, bio, статистика, редактирование.
4. Просмотр профилей других пользователей.
5. Лента постов: все, подписки, популярное.
6. Посты до 280 символов, поддержка @mentions и #hashtags.
7. Лайки, репосты, комментарии, закладки.
8. Подписка и отписка.
9. Уведомления: лайк, комментарий, репост, подписка, упоминание.
10. Поиск по пользователям и постам.
11. Светлая и тёмная тема.
12. Адаптивный интерфейс: desktop с боковыми панелями, mobile с нижним меню.
13. Админ-панель: пользователи онлайн, количество авторизаций, список пользователей, удаление постов, блокировка пользователей.
14. Модерация: жалобы, скрытие постов, антиспам, фильтр запрещённых слов.
15. Безопасность: Zod validation, rate limiting, защита от XSS, проверка загружаемых файлов.

Порядок разработки:
Шаг 1. Инициализация проекта и docker-compose.
Шаг 2. Prisma schema и миграции.
Шаг 3. Auth API: регистрация, вход, refresh, logout.
Шаг 4. Профили пользователей.
Шаг 5. CRUD постов и загрузка аватарок/изображений.
Шаг 6. Лента, подписки, профили других пользователей.
Шаг 7. Лайки, комментарии, репосты, закладки.
Шаг 8. Уведомления и Socket.IO.
Шаг 9. Поиск, хештеги, популярное.
Шаг 10. Админ-панель и модерация.
Шаг 11. Финальная UI-полировка, анимации, skeleton loaders, infinite scroll.

Для маленькой версии на HTML/CSS/JS:
- Раздели код на index.html, styles.css, db.js, auth.js, pages.js, admin.js, app.js.
- Базу данных храни в localStorage через отдельный модуль db.js.
- Сделай отдельный аккаунт администратора: admin@anon.ru / admin123.
- Интерфейс должен быть красивым, адаптивным, с анимациями, тёмной темой и понятными вкладками.
